# Hava Nöbeti

Public GitHub Pages deployment for the Hava Nöbeti weather alert app.

Enable Pages in the repository settings and publish from the `main` branch root. The site is static and requests forecast/geocoding data directly from Open-Meteo. Coordinates are sent to Open-Meteo to provide forecasts and stored in the visitor’s browser. This is not an official emergency alert service.

Open-Meteo free API is for non-commercial use; weather data is CC BY 4.0.
